# كتالوج تصاميم الفساتين

نسخة بسيطة تعمل بـ HTML + CSS + JavaScript فقط.

## التشغيل

1. فك الضغط.
2. افتحي `index.html` في المتصفح.
3. ضعي صور الفساتين داخل مجلد `images`.
4. افتحي `script.js` وعدّلي قائمة `dresses`:
   - الاسم
   - التصنيف
   - اسم ملف الصورة

مثال:
{
  id: 7,
  name: "فستان أسود",
  category: "evening",
  categoryName: "سهرة",
  image: "images/black-dress.jpg"
}

## تغيير مدة الجلسة

في `script.js`:

const SESSION_SECONDS = 120;

120 = دقيقتان
300 = خمس دقائق
60 = دقيقة واحدة

## QR Code

بعد رفع الموقع على رابط عام، اجعلي الـ QR يفتح رابط `index.html`.

مهم:
- هذا المشروع Frontend فقط.
- لا توجد قاعدة بيانات.
- لا توجد لوحة تحكم.
- حماية Screenshot الكاملة غير ممكنة في موقع HTML عادي.
- إذا أردتِ حماية أقوى لاحقاً، نحتاج Backend أو تطبيق Native.
